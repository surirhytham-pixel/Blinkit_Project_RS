🛒 Blinkit Sales Analysis Dashboard (Power BI)
📌 Project Overview

This project analyzes sales performance on a quick-commerce platform similar to Blinkit using an interactive Power BI dashboard.

The goal was to move beyond simple visualizations and focus on extracting actionable business insights that can help improve decision-making in fast-paced delivery platforms.

🎯 Objectives
Analyze sales trends across different city tiers
Understand product category performance
Evaluate outlet-level contribution to revenue
Identify key drivers influencing overall sales
🔍 Key Insights
Tier 3 cities contribute the highest share of total revenue, outperforming Tier 1 and Tier 2
Low-fat products dominate total sales, indicating changing consumer preferences
Supermarket Type 1 outlets lead in both revenue and item count
Top-performing categories include:
Fruits
Snacks
Household items
